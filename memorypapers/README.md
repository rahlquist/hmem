# memorypapers — Source Document Index

This directory originally held 10 source papers (PDF/DOCX) plus one ZIP bundle
(`AI_memory.zip`) that informed the `memory_paper.md` analysis. To keep the repo
lightweight, the binary documents were removed from version control; this index
preserves their titles and provenance so they can be re-fetched if needed.
