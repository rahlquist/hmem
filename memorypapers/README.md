# memorypapers — Source Document Index

This directory originally held 10 source papers (PDF/DOCX) that informed the
`memory_paper.md` analysis. To keep the repo lightweight, the binary documents
were removed from version control; this index preserves their titles and
provenance so they can be re-fetched if needed.

## Note

The extracted plain-text versions of papers 1–10 (`.txt`) were generated
locally with PyMuPDF during analysis and are not retained in the repo. To
regenerate: `pip install pymupdf` then extract each PDF.
